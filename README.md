# campus-lost-found-system
基于 SpringBoot 的校园失物招领系统，毕业设计&产品实践项目

## 📌 项目简介
面向高校师生场景的失物招领平台，从真实校园痛点出发完成需求调研、产品方案设计、业务流程梳理、后端开发实现。
平台支持学生发布寻物/招领启事、物品检索、认领申请；管理员负责帖子审核、用户管理、公告发布、数据统计。
本项目完整走完从场景挖掘、功能建模、方案落地到用户反馈迭代的产品闭环，是我业务拆解、需求转化能力的实践。

## 🛠 技术栈
后端：SpringBoot + MyBatis + MySQL
工具：ProcessOn（功能结构图、流程图）、Postman接口调试

## ✨ 核心功能模块
### 学生端
账户注册登录、个人信息管理；浏览&检索启事；发布寻物/招领信息；提交认领申请；查看认领状态；个人发布与认领记录

### 管理员端
用户管理（新增、禁用）、帖子审核、启事管理、公告管理、物品类型维护、数据统计

## 🎯 项目收获
1. 调研校园真实场景，挖掘用户痛点，把零散诉求整理成结构化可落地的产品方案，输出功能模块图、业务流程图
2. 和开发对齐需求，推动功能落地，收集模拟用户反馈持续优化检索、审核流程
3. 建立简单的数据评估思路，通过发帖量、认领成功率衡量产品价值
4. 熟悉B端业务系统的权限、审核类流程设计，锻炼问题拆解能力

> 近期在学习大模型与Agent相关技术，正在尝试为本系统增加AI物品智能匹配Agent，自动匹配寻物与招领信息，探索AI在校园业务场景的落地。
